A Node.js and Express REST API for creating, viewing, updating and deleting student event proposal records. PostgreSQL provides persistent storage.

## Requirements

- Node.js 20 or newer (active LTS recommended)
- npm
- A PostgreSQL database
- Postman or another API client for testing

## Install and run locally

1. Open this folder in VS Code.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Copy `.env.example` to `.env` and set `DATABASE_URL` to the PostgreSQL connection string. Keep `.env` private; it is excluded from Git.
4. In the database SQL editor, run `schema.sql` once to create the table.
5. Run `seed.sql` once to insert eight fictional sample proposals.
6. Start the API:

   ```bash
   npm start
   ```

7. Open `http://localhost:3000/` and `http://localhost:3000/health`.

Do not run `seed.sql` repeatedly unless you intentionally want duplicate sample records.

## API routes

| Method | Route | Purpose | Success |
|---|---|---|---|
| GET | `/` | API guide | 200 |
| GET | `/health` | API/database health | 200 |
| GET | `/api/records` | List proposals | 200 |
| GET | `/api/records/:id` | Get one proposal | 200 |
| POST | `/api/records` | Create proposal | 201 |
| PUT | `/api/records/:id` | Replace editable fields | 200 |
| DELETE | `/api/records/:id` | Delete proposal | 200 |

### POST and PUT JSON body

Send all four editable fields. Do not send `id`.

```json
{
  "title": "Computer Science Career Fair",
  "category": "Academic",
  "description": "A student-organised event connecting learners with technology professionals.",
  "status": "Pending"
}
```

Validation rules:

- `title`: 3–80 characters
- `category`: 2–40 characters
- `description`: 5–300 characters
- `status`: exactly `Pending`, `In progress` or `Completed`
- `id`: generated by PostgreSQL; route IDs must be positive whole numbers

Errors are JSON objects containing `message`. Status codes: 400 invalid input, 404 missing record/route, 500 unexpected server error, and 503 database health-check failure.

## Database notes

`schema.sql` creates the `records` table. `seed.sql` inserts eight fictional examples. PostgreSQL identity columns generate record IDs. The API uses parameterised SQL queries.

## Deployment notes

For Render or another Node.js host:

- Build command: `npm install`
- Start command: `npm start`
- Set `DATABASE_URL` to the hosted PostgreSQL connection string in the host's environment settings.
- Set `NODE_ENV=production`.
- Set `CLIENT_ORIGINS` to comma-separated frontend origins when the Activity 8 frontend is ready. Do not include URL paths or a trailing slash.
- Never commit `.env`, database passwords or connection strings.

After deployment, test `/health` and every CRUD route using the live HTTPS base URL. The live URL is not known yet and must be added after the hosting service is created.
